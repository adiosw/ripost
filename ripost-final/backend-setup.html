📖 Instrukcja dla laika

Jak podpiąć
działający backend

Instrukcja krok po kroku — od zera do działającego logowania, historii sesji i płatności. Nie musisz znać programowania. Wystarczy kopiować i wklejać dokładnie tak jak opisano.

⏱️

Szacowany czas: 45–75 minut przy pierwszym podejściu. Całość jest bezpłatna (poza Stripe który pobiera prowizję 1.4% + 0,25 zł dopiero gdy ktoś zapłaci).

🗺️

Co będziesz potrzebować

Trzy zewnętrzne serwisy — wszystkie mają darmową warstwę wystarczającą na start.

📋 Lista kont do założenia (wszystkie bezpłatne)
  • 1
    Supabase — baza danych PostgreSQL + logowanie użytkowników. Free: 500 MB, 50 000 użytkowników/mies. Wystarczy na lata.
  • 2
    Groq — API do modelu LLaMA 3.1 (silnik AI w czacie). Free: ~14 400 requestów/dzień. W zupełności wystarczy na testy i mały ruch.
  • 3
    Stripe — płatności online (BLIK, karta, PayPal). Bezpłatne konto — prowizja tylko od prawdziwych transakcji.
  • 4
    Netlify (opcjonalnie) — hosting strony. Free: wystarczy na duży projekt. Drag-and-drop deploy.
⚠️

Klucze API to hasła. Nigdy nie wrzucaj ich na GitHuba ani nie udostępniaj. Trzymaj w pliku lokalnym lub w zmiennych środowiskowych Netlify.

Supabase — utwórz projekt

Supabase to baza danych + logowanie w jednym. Klika się jak aplikację, nie wymaga serwera.

🖱️ Tworzenie projektu — krok po kroku
  • 1
    Wejdź na supabase.com → kliknij "Start your project"
  • 2
    Zaloguj się przez GitHub (najłatwiej) lub utwórz konto emailem
  • 3
    Kliknij "New Project" → wybierz organizację (domyślna jest OK)
  • 4
    Wpisz nazwę projektu: np. ripost-production
  • 5
    Kliknij "Generate" przy haśle bazy danych → ZAPISZ HASŁO gdzieś (notatnik)
  • 6
    Region: wybierz "West EU (Ireland)" — najbliżej Polski
  • 7
    Kliknij "Create new project" → poczekaj ~2 minuty na inicjalizację

2

Baza danych — uruchom SQL

Skopiuj poniższy kod SQL i wykonaj go w Supabase. Stworzy wszystkie potrzebne tabele, zabezpieczenia i trigger automatyczny w jednym kliknięciu.

🖱️ Jak wykonać SQL w Supabase
  • 1
    W Supabase kliknij "SQL Editor" (ikona kodu w lewym pasku)
  • 2
    Kliknij "New query"
  • 3
    Skopiuj cały kod SQL poniżej (przycisk "Kopiuj") i wklej do edytora
  • 4
    Kliknij zielony przycisk "Run" (lub Ctrl+Enter)
  • 5
    Powinieneś zobaczyć napis "Success" — tabele gotowe
SQL — wklej do Supabase SQL Editor
-- ══════════════════════════════════════════════
   RIPOST — SCHEMA BAZY DANYCH
   Wklej do SQL Editor w Supabase i kliknij Run
══════════════════════════════════════════════

-- 1. Profile użytkowników
CREATE TABLE IF NOT EXISTS user_profiles (
  id          UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  email       TEXT,
  full_name   TEXT,
  avatar_url  TEXT,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Plany zakupione przez Stripe
CREATE TABLE IF NOT EXISTS user_plans (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  plan            TEXT NOT NULL,   -- 'starter' | 'pro' | 'unlimited'
  sims_left       INT DEFAULT 0,
  expires_at      TIMESTAMPTZ,
  stripe_sub_id   TEXT,
  created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Historia sesji treningowych
CREATE TABLE IF NOT EXISTS sessions (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  scenario        TEXT NOT NULL,
  score           INT,
  feedback        TEXT,
  messages_count  INT DEFAULT 0,
  created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- 4. Leady z formularzy
CREATE TABLE IF NOT EXISTS leads (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email       TEXT UNIQUE NOT NULL,
  source      TEXT DEFAULT 'demo',
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- ══ TRIGGER: auto-profil po rejestracji ══
CREATE OR REPLACE FUNCTION handle_new_user()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO public.user_profiles (id, email)
  VALUES (NEW.id, NEW.email)
  ON CONFLICT (id) DO NOTHING;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE OR REPLACE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE PROCEDURE handle_new_user();

-- ══ RLS: każdy widzi tylko swoje dane ══
ALTER TABLE user_profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE user_plans    ENABLE ROW LEVEL SECURITY;
ALTER TABLE sessions      ENABLE ROW LEVEL SECURITY;
ALTER TABLE leads         ENABLE ROW LEVEL SECURITY;

CREATE POLICY "users_own_profile"  ON user_profiles FOR ALL USING (auth.uid() = id);
CREATE POLICY "users_own_plan"     ON user_plans    FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "users_own_sessions" ON sessions      FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "anyone_insert_lead" ON leads
  FOR INSERT WITH CHECK (true);
✅

Po wykonaniu SQL sprawdź zakładkę Table Editor w Supabase — powinny pojawić się 4 tabele: user_profiles, user_plans, sessions, leads.

3

Logowanie — konfiguracja auth

Supabase obsługuje email+hasło od razu po wyjęciu z pudełka. Możesz też dodać Google OAuth.

Email + hasło (włączone domyślnie)

🖱️ Sprawdź ustawienia
  • 1
    Supabase → Authentication → Providers
  • 2
    Sprawdź że Email jest włączony (toggle zielony) — domyślnie jest
  • 3
    Gotowe — użytkownicy mogą się rejestrować emailem i hasłem

Google OAuth (opcjonalnie — łatwiejsze logowanie dla użytkowników)

🖱️ Dodanie Google OAuth
  • 1
    Supabase → Authentication → Providers → kliknij Google → włącz
  • 2
    Skopiuj Callback URL który pokazuje Supabase (potrzebny w Google Console)
  • 3
    Wejdź na console.cloud.google.com → utwórz projekt → APIs & Services → Credentials
  • 4
    Utwórz OAuth 2.0 Client ID, typ: Web Application → dodaj Callback URL z Supabase
  • 5
    Skopiuj Client ID i Client Secret → wklej do Supabase → Save
💡

Na start wystarczy samo email+hasło. Google OAuth możesz dodać później w dowolnym momencie bez zmiany kodu.

Groq — klucz do AI

Groq udostępnia model LLaMA 3.1 70B przez API. Bezpłatny plan wystarcza na tysiące rozmów miesięcznie.

🖱️ Jak uzyskać klucz Groq API
  • 1
    Wejdź na console.groq.com
  • 2
    Kliknij "Sign Up" → zarejestruj się (Google lub email)
  • 3
    W dashboardzie kliknij "API Keys" w lewym menu
  • 4
    Kliknij "Create API key" → wpisz nazwę (np. ripost-prod)
  • 5
    Skopiuj klucz NATYCHMIAST — pojawia się tylko raz! Zaczyna się od gsk_...

📋 Masz teraz:

GROQ_API_KEYgsk_twójklucz... (długi ciąg)
⚠️

Free tier Groq: ~14 400 requestów/dzień lub ok. 100 000 tokenów/min. Dla testów i małej produkcji w zupełności wystarczy. Płatne plany dostępne gdy przekroczysz limity.

Stripe — konfiguracja płatności

Stripe obsługuje BLIK, kartę i PayPal. Tworzysz produkty w panelu, kopiujesz ID — gotowe.

🖱️ Konfiguracja Stripe — krok po kroku
  • 1
    Wejdź na stripe.com → zarejestruj się
  • 2
    W dashboardzie górne menu → Products → "Add product"
  • 3
    Utwórz 3 produkty (szczegóły poniżej)
  • 4
    Po zapisaniu każdego produktu kliknij go → skopiuj Price ID (zaczyna się od price_...)
  • 5
    Stripe → Developers → API Keys → skopiuj Publishable key (pk_live_...)
📦 Produkty do stworzenia w Stripe
  • A
    Ripost Próbny — cena: 29 PLN — typ: One time → skopiuj Price ID
  • B
    Ripost Pro — cena: 49 PLN — typ: One time → skopiuj Price ID
  • C
    Ripost Unlimited — cena: 99 PLN — typ: Recurring, monthly → skopiuj Price ID

📋 Masz teraz 4 wartości Stripe:

STRIPE_PUBLISHABLEpk_live_twójklucz...
PRICE_STARTERprice_xxxxxxxxxxxx (29 zł)
PRICE_PROprice_xxxxxxxxxxxx (49 zł)
PRICE_UNLIMITEDprice_xxxxxxxxxxxx (99 zł/mies.)
⚠️

Zacznij od trybu testowego (klucz pk_test_...). Stripe ma testowe karty (np. 4242 4242 4242 4242). Przełącz na produkcję gdy wszystko działa.

Deploy — wrzuć na Netlify

Najprościej jak można — przeciągnij folder z plikami na stronę Netlify.

🖱️ Publikowanie strony (drag and drop)
  • 1
    Wejdź na netlify.com → zaloguj się (GitHub lub email)
  • 2
    Na dashboardzie znajdź pole "Drag and drop your site folder here"
  • 3
    Rozpakuj ZIP i przeciągnij cały folder ripost-v6/ na to pole
  • 4
    Netlify nada Ci losowy URL np. hopeful-morse-123.netlify.app
  • 5
    Site settings → Change site name → zmień na ripost (dostaniesz ripost.netlify.app)

Dodaj Supabase Redirect URL

🔐 Skonfiguruj domenę w Supabase
  • 1
    Supabase → Authentication → URL Configuration
  • 2
    W polu "Site URL" wpisz: https://ripost.netlify.app
  • 3
    W "Redirect URLs" dodaj: https://ripost.netlify.app/**
  • 4
    Kliknij Save → gotowe!
🎉

Strona jest live! Możesz teraz zarejestrować konto testowe i sprawdzić czy logowanie i zapis sesji działają.
